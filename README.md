# ShotDay — календарь съёмок

Шаг 1: Telegram-бот + облачная база + сканер чатов. Шаг 2 (Android-приложение) — позже, поверх той же базы.

## Что умеет сейчас

- Пишешь боту обычным текстом («завтра в 15 food у Bon, 3 рилса») → карточка «Записать съёмку?» → ✅ Добавить / ✏️ Изменить / 🗑 Не то.
- Напоминания: 🔋 «Заряди» накануне в 20:00, 🎒 «Собери» за 3 часа, 🚗 «Выезжай» за час. В напоминаниях есть чек-лист с галочками и кнопки «+30 мин» / «+1 час».
- Чек-лист техники подставляется по типу съёмки (Reels, Food, Интервью, Реклама…). Список техники и шаблоны лежат в таблицах `gear_items` и `gear_templates`.
- Референсы: ответь на карточку съёмки ссылкой, фото, видео или голосовым, и они прикрепятся к ней.
- /today, /tomorrow, /week, /next, /gear. Утром в 9:00 приходит дайджест на день.
- Сканер раз в 2 часа читает новые сообщения в личных чатах и группах до 30 человек, кроме чёрного списка. Договорённости, переносы и отмены приходят в бот на подтверждение, сам он ничего не создаёт. Работает только на чтение: отправка и отметка «прочитано» заблокированы в коде.

## Что нужно для запуска

| Что | Где взять |
|---|---|
| `BOT_TOKEN` | @BotFather → /newbot |
| `OWNER_TG_ID` | @userinfobot |
| `DATABASE_URL` | supabase.com → новый проект → Connect → Session pooler (URI). Затем SQL Editor → выполнить `server/schema.sql` |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys (пополнить на $5, этого хватит надолго) |
| `TG_API_ID`, `TG_API_HASH` | my.telegram.org → API development tools (те же, что для скрипта чтения чатов) |

## Установка на сервер

```bash
git clone <repo> ~/shotday && cd ~/shotday/server
bash deploy/install.sh            # создаст .env из шаблона
nano .env                         # заполнить
.venv/bin/python -m shotday.scanner_login   # один раз: телефон + код из Telegram
bash deploy/install.sh            # запустит бота и сканер (systemd)
```

Логи: `journalctl -u shotday-bot -f`, `journalctl -u shotday-scanner -f`.
